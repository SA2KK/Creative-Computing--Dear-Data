# Silicon Bloom

An initial Processing sketch that presents 25 historical processor
records as a small garden of flowers. Flower size represents a range of
transistor counts, and colour represents the era. Hover over a flower in the
sketch to see the chip, year and count.

## Run the sketch

Open `transistor_timeline_v1.pde` in Processing and press Run.

## Data

The sketch's arrays contain the values used for drawing. The same 25 records
are also provided in [`data/transistor_data_v1.csv`](data/transistor_data_v1.csv),
with the source URL for each record.

Intel processor counts are from Intel's [Microprocessor Quick Reference
Guide](https://www.intel.com/pressroom/kits/quickreffam.htm). Apple M1, M2, M3
and M4 counts are from Apple's official announcements:

- [Apple M1](https://www.apple.com/newsroom/2020/11/apple-unleashes-m1/)
- [Apple M2](https://www.apple.com/newsroom/2022/06/apple-unveils-m2-with-breakthrough-performance-and-capabilities/)
- [Apple M3](https://www.apple.com/ie/newsroom/2023/10/apple-unveils-m3-m3-pro-and-m3-max-the-most-advanced-chips-for-a-personal-computer/)
- [Apple M4](https://www.apple.com/newsroom/2024/05/apple-introduces-m4-chip/)

These are selected processor milestones, not one observation for every year.

I will add more details later on and make the data more segmented.
